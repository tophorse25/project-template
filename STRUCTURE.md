# Repository Structure

```
├── CLAUDE.md               # AI assistant instructions
├── PROJECT.md              # Project overview, stage, module progress
├── TODO.md                 # Task tracking
├── UPDATE_LOG.md           # Milestone log
├── session-handoff.md      # Context for next session
├── STRUCTURE.md            # This file
├── README.md               # Project README
├── .gitmessage             # Commit message template
├── .gitignore              # Git ignore rules
│
├── .claude/
│   └── candidates.md       # AI-generated improvement candidates
│
├── log/
│   └── session-*.md        # Detailed session logs
│
├── feedback/               # Mentor feedback files
├── meetings/               # 1:1 meeting notes
├── docs/                   # Project documentation
│
└── src/                    # Your project source code
```
