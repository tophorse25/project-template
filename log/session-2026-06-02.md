## Insights

- [Architecture] Cross-run accumulation (evidence keyed by canonical URL + `score_history`) is the real
  answer to thin data — `super_crawler`'s own "memory is the differentiator" insight, never implemented
  there for live data.
- [Architecture] Separating signal_strength from confidence and reporting `adjusted_score` keeps thin
  data honest: a theme seen once reads "insufficient/needs_more_evidence", never "validated".
- [Architecture] Deterministic + no external API = reproducible and auditable; a feature, not a limit.
